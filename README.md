# NomNom

## Description

NomNom allows you to **explore meals** from different categories and discover **random recipes**.
Perfect for foodies looking for inspiration in the kitchen!

## Goal

- Learn React 
    - [Describing the UI](https://react.dev/learn/describing-the-ui)
    - [Adding Interactivity](https://react.dev/learn/adding-interactivity)
    - [Managing State](https://react.dev/learn/managing-state)
    - [Escape Hatches](https://react.dev/learn/escape-hatches)
- Learn [React Router](https://reactrouter.com/start/modes) (Declarative mode)
- Work with an external [API](https://www.themealdb.com/api.php) from TheMealDB

## Requirements

Before getting started, make sure you have the following installed:

- Node.js (v24.14.0)

## Getting Started

Open a CLI (Command Prompt, PowerShell or Terminal) and run:

```bash
git clone https://github.com/RL08/NomNom.git
cd NomNom
npm install
npm run dev
```
